# Pawcus 포인핸드 확장 프로그램

포인핸드 웹 공고에서 실행되는 학습·발표용 Chrome/Edge 확장 프로그램 초안입니다.

## 원칙

- 동물 사진·공고·보호소 정보는 현재 포인핸드 웹 공고에 표시된 값만 읽습니다.
- 공고에 없는 동물 특성은 만들거나 추정하지 않습니다.
- 하트로 담은 비교 후보와 설문 답은 확장 프로그램의 브라우저 저장소에만 보관합니다. 포인핸드 공식 관심목록과 연동하지 않습니다.
- 포인핸드와 공식 제휴한 서비스가 아닙니다.

## 현재 구현

- 포인핸드 모든 웹페이지의 Pawcus 챗봇 버튼과, 공고 상세의 Pawcus 전용 하트 버튼
- 최대 3마리 후보 보관과 비교 화면
- 기본 매칭 14문항, 신청서 준비 11문항, 지역 선택의 한 문항씩 진행 화면
- 등록 완료 2초 화면과 최소 2초 추천 로딩 화면
- 현재 브라우저에서 열어 본 포인핸드 공고를 지역 조건으로 제한해 최대 3건 표시

## 디자인 방향

- 포인핸드 계열 노랑(`#FFD400`)을 핵심 행동 버튼·아이콘·진행 바로만 사용합니다.
- 따뜻한 크림 배경과 흰 카드, 짙은 글자로 정보를 정리합니다.
- 강아지 얼굴 아이콘과 등록 완료·로딩 상태의 강아지/고양이 모션만 귀여운 포인트로 사용합니다.

## 아직 구현하지 않은 것

- 포인핸드 공식 API·로그인·관심목록 연동
- 공고 전체 자동 수집
- 공고에 없는 속성을 사용한 점수화

## 로컬 설치 확인

1. Chrome 또는 Edge에서 `확장 프로그램` 관리 페이지를 연다.
2. `개발자 모드`를 켠다.
3. `압축해제된 확장 프로그램을 로드`를 누른다.
4. 이 `extension` 폴더를 고른다.
5. 포인핸드 동물 공고 상세 페이지를 새로고침한다.

설치는 사용자 브라우저 설정을 바꾸는 작업이므로, 구현 검증 뒤 사용자가 직접 하거나 별도 확인을 받은 뒤 진행한다.
